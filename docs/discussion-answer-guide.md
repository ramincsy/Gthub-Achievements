# Discussion answer guide

Use this checklist when responding to a repository Q&A discussion:

1. Restate the observed problem and the requested outcome.
2. 2. Give a reproducible command or a precise GitHub UI path.
   3. 3. Explain any trade-offs, especially when history or attribution can be rewritten.
      4. 4. Verify the result on the final branch, and mention relevant checks.
         5. 5. Keep the answer focused and avoid credentials, tokens, or automation-only claims.
           
            6. For attribution questions, inspect the final commit message and confirm the expected human trailers are present without unexpected bot trailers. Keep the final branch as the source of truth.
